# 🚀 Mini Sentiment Analyzer

A lightweight Natural Language Processing (NLP) project that performs binary sentiment classification using sentence embeddings and machine learning.

The project converts text into semantic vector representations using Sentence Transformers and classifies sentiment using a Support Vector Classifier (SVC).

---

## 📌 Project Overview

This project demonstrates how modern text embeddings can be combined with traditional machine learning algorithms to perform sentiment analysis.

Instead of relying on bag-of-words or TF-IDF features, the model uses dense semantic embeddings generated by Sentence Transformers. These embeddings capture contextual meaning within text and are then used to train a Support Vector Classifier for sentiment prediction.

The final model achieved an accuracy of approximately **83.77%** on the test dataset.

## 📊 Dataset

A custom manually-created sentiment dataset was used for training.

The dataset contains:

| Category                | Samples |
| ----------------------- | ------- |
| Positive Reviews        | 20      |
| Negative Reviews        | 20      |
| Neutral / Mixed Reviews | 20      |
| Slight Positive Reviews | 10      |
| Slight Negative Reviews | 10      |
| Total Samples           | 80      |

### Label Mapping

| Label | Meaning            |
| ----- | ------------------ |
| 1     | Positive Sentiment |
| 0     | Negative Sentiment |

Neutral and mixed reviews were intentionally included to make classification more challenging and realistic.

Examples:

**Positive**

* "I love this product"
* "Fantastic experience"
* "Highly recommend it"

**Negative**

* "Worst experience ever"
* "Terrible product"
* "Highly disappointing"

**Neutral / Mixed**

* "It was okay"
* "Could be better"
* "I have mixed feelings"

## 🧠 Model Architecture

### 1. Sentence Embeddings

The project uses Sentence Transformers to convert raw text into dense numerical vectors.

Benefits:

* Captures semantic meaning
* Handles similar sentences effectively
* Produces fixed-length embeddings
* Requires minimal feature engineering

### 2. Support Vector Classifier

The generated embeddings are passed to a Support Vector Classifier (SVC).

Reasons for choosing SVC:

* Performs well on small datasets
* Effective in high-dimensional spaces
* Strong baseline for text classification tasks

## 💡 Embedding Efficiency Idea

A future optimization considered during development is reducing embedding computation by limiting excessively long inputs before generating embeddings.

### Proposed Approach

Instead of embedding an entire long document:

1. Keep only the most relevant portion of text.
2. Truncate unnecessary tokens beyond a chosen threshold.
3. Generate embeddings on the shortened text.

Potential benefits:

* Faster inference
* Reduced memory usage
* Lower computational cost
* Better scalability for large volumes of text

This idea was noted for future experimentation and was not implemented in the current version.
